## 🛠️ Troubleshooting

### Problem: Application Doesn't Open
**Solution**: Make sure you're using the latest version of your browser. Clear your browser cache and try reopening the file.

### Problem: Avatars Look Distorted
**Solution**: Check that you haven't accidentally linked eyes when you wanted them independent. Reset the avatar to default settings and start fresh.

### Problem: Can't Export My Project
**Solution**: Ensure you have enough storage space on your computer. Try exporting with a shorter filename.
